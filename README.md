# Git Changelog Generator

An open-source CLI tool powered by AI to automatically generate structured Git commit messages and changelogs.

## 🚀 Features
- **Auto Commit Messages:** Generates concise and formatted commit messages based on staged changes.
- **Changelog Automation:** Builds Markdown changelogs from project history.
- **Open Source:** Built for developers and open to contributions.

## 🛠️ Built With
- Python 3.10+
- Anthropic Claude API
